# 一致性审查

审查权利要求与说明书的一致性。

## 审查要点

1. **术语一致性** - 权利要求和说明书使用相同术语
2. **特征对应性** - 权利要求特征在说明书中有对应描述
3. **范围一致性** - 保护范围与说明书公开内容一致
4. **引用一致性** - 附图标号、公式编号一致

## 常见问题

- 权利要求使用的术语在说明书中未出现
- 说明书描述与权利要求限定不一致
- 附图标号错误或不对应

## Agent 与工具边界

- 一致性审查可以参考 `compliance_checker`、`support_verifier` 等工具信号，但最终不一致项由质量审查 Agent 判断。
- 附图审查必须检查：是否缺图、图号是否重复、附图标题是否重复拼接、正文/附图说明/实际图片是否一致。
- 如果申请文件引用了图1至图N，但 `drawings` 中缺少对应文件，必须判定为不可通过。
