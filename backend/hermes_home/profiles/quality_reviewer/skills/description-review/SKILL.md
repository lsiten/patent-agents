# 说明书审查

审查说明书的公开充分性和完整性。

## 审查维度

### 公开充分性
- 本领域技术人员能否实现
- 技术方案是否完整
- 关键参数是否提供

### 完整性
- 说明书各部分是否齐全
- 实施例是否充分
- 附图说明是否完整

### 实施例覆盖
- 实施例是否覆盖权利要求
- 是否有多个实施例
- 边界情况是否考虑

## 工具使用

- `support_verifier` - 验证说明书对权利要求的支持

## Agent 与工具边界

- `support_verifier` 只验证显式支持关系和结构完整性线索。
- 公开是否充分、实施方式是否能够实施、摘要和发明内容是否准确，必须由质量审查 Agent 结合专利审查标准判断。
- 如果发现逐字稿时间戳、说话人、口语化内容进入说明书，应作为内容质量问题退回撰写 Agent。
