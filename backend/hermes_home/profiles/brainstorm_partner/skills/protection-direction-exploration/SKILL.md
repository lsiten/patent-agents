# 保护方向探索

探索技术方案的多种专利保护方向。

## 探索维度

1. **核心方法保护** - 技术方案的核心算法/方法
2. **系统架构保护** - 整体系统结构
3. **关键模块保护** - 独立可复用的模块
4. **应用场景保护** - 特定应用场景的实现

## 布局策略

- **横向布局** - 覆盖多个应用领域
- **纵向布局** - 从上位到下位层层保护
- **防御性布局** - 阻止竞争对手绕过

## 工具使用

- `creative_thinking` - 提取候选发散方向
- `patent_strategy_guide` - 整理申请策略候选项和检查清单

## Agent 与工具边界

- 工具只提供保护方向候选、策略模板和发散线索。
- 哪些方向适合当前发明、哪些方向应作为主保护或从属保护，必须由头脑风暴 Agent 结合用户确认和专利经验判断。
- 不得把工具建议原样输出为最终保护策略；必须转化为可让用户确认的具体方案。
