# 权利要求硬格式

## 独权

权利要求1只能采用 3 步或 4 步：

```text
1. 一种……方法，其特征在于，包括：
S1，……；
S2，……；
S3，……。
```

或：

```text
1. 一种……方法，其特征在于，包括：
S1，……；
S2，……；
S3，……；
S4，……。
```

## 标点换行

- 每个 `；` 后必须换行。
- 每个 `。` 后必须换行。
- 不要把多个步骤挤在同一自然段。

## 从权

- 从权必须写成“根据权利要求N所述的……，其特征在于，……”。
- N 必须小于当前权利要求编号。
- 从权按核心细化、参数/条件、替代实现、系统对应的顺序递进。
